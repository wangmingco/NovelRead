# 墨读 · InkRead

一个**把小说存在浏览器里**的移动端网页阅读器。纯静态、零依赖、无后端。

书籍以 **gzip 压缩包**的形式放在服务器上，前端下载后用浏览器原生的
`DecompressionStream` 解压、切章，再存进 IndexedDB —— 之后完全离线可读，
并且永远记得你上次读到哪一页。一本 **1400 万字、4515 章**的书，
下载 + 解压 + 解析 + 入库只要 **2 秒多**，打开只要 **0.3 秒**。

界面取向是「纸与墨」：暖白纸底、墨色正文、朱砂印章式的点缀，
四个配色主题（纸 / 护眼 / 夜 / 纯黑），为手机竖屏专门优化。

## 快速开始

必须通过 HTTP 打开（`file://` 下浏览器不允许 fetch 本地文件）。

**Windows：双击根目录的 `start.bat`** —— 它会自动挑一个空闲端口（默认 5173）、
优先用 `node tools/serve.mjs`（没有 Node 就退回 `python -m http.server`）、
并把手机访问用的内网地址打印出来，最后自动打开浏览器。

也可以手动起服务：

```bash
npm start          # = node tools/serve.mjs，默认 5173 端口
python -m http.server 5173 --bind 0.0.0.0     # 或者用 Python
```

### 在手机上调试

1. 手机和电脑连同一个 Wi-Fi。
2. 用 `start.bat` 打印出来的 `On phone:` 内网地址访问（形如 `http://192.168.x.x:5173/`）。
3. 「添加到主屏幕」安装，就得到一个全屏、无地址栏的阅读 App。

| 两种翻页 | **左右翻页**（横滑/点两侧/键盘）与 **上下滚动**，随时切换 |

## 换书 / 加书

1. 把 GBK 或 UTF-8 的 `.txt` 丢进 `data/books/`。
2. 在 `tools/build-books.mjs` 顶部的 `BOOKS` 里加一条（id / 书名 / 作者 / 简介 / 标签）。
3. 跑 `npm run build`，它会：
   - 自动识别编码（UTF-8 / GB18030）并转成 UTF-8
   - 按「第一章」「卷一」「洪武大帝 第一章 童年」等规则切分章节
   - 清掉盗版站塞进来的广告 `<script>` / HTML / 多层实体转义
   - 丢掉只有标题没有正文的分卷标记
   - gzip 压缩成 `data/books/<id>.json.gz`
   - 重新生成 `data/books.json`（含章数、字数、体积）
4. `npm test` 会校验清单、压缩包、乱码率、HTML 残留等。

> 源文件不在了也没关系：只要 `data/books/<id>.json.gz` 还在，
> `npm run build` 会基于现有压缩包重新清洗一遍。

### 清单格式 `data/books.json`

```json
{
  "books": [
    {
      "id": "guanxian",
      "title": "官仙",
      "author": "陈风笑",
      "intro": "简介，显示在详情页",
      "tags": ["仙侠", "官场"],
      "format": "json",
      "compress": "gzip",
      "url": "data/books/guanxian.json.gz",
      "words": 14017185,
      "chapterCount": 4515,
      "size": 17462295
    }
  ]
}
```

`url` **相对站点根目录**解析（不是相对清单文件），所以部署到任何子路径都能用。

## 数据存在哪

- **正文 / 阅读进度 / 书签** → IndexedDB（库名 `inkread`），不会上传到任何服务器。
- **阅读设置** → localStorage，页面一加载就生效，避免主题闪烁。
- 每本书拆成两部分存储：**目录**（`books` 表，只有标题字符串）和
  **正文分片**（`chunks` 表，每 40 章一片）。所以打开一本 1400 万字的书，
  内存里只有目录 + 当前那一片（约 100 KB），翻到别处再按需载入。
- 书签记的是「章节序号 + 章内比例」，换字号、换字体、横竖屏旋转后位置依然准确。
- 下载完成后会调用 `navigator.storage.persist()` 申请持久化存储，
  书架底部会显示当前是否已持久化。

> 数据属于「这个浏览器 + 这个域名」。换浏览器、换域名、清空站点数据都会丢。

## 实现要点

**解压**：前端不依赖任何第三方库。用 fetch 读成字节后按魔数判断——`1f 8b` 走
`DecompressionStream('gzip')`，`PK\x03\x04` 自己解析 zip 中央目录再用
`DecompressionStream('deflate-raw')`。如果服务器已经配了 `Content-Encoding: gzip`
替我们解过压，字节就是纯文本，直接按 UTF-8 解码 —— 三种情况都能正确处理。

**分页**：CSS 多栏 + 原生横向滚动容器。正文被固定成「一页宽、一页高」的多栏盒子，
内容向左溢出成更多栏，父容器横向滚动带原生惯性，松手后吸附到整页。
页数用两种独立方法各算一次取较大值（容器 `scrollWidth` 和最后一个元素的
`getBoundingClientRect`），避免个别浏览器 `scrollWidth` 不可靠。列间距（44px）
特意大于容器左右内边距（21px），否则换页时会在留白里露出上一页的尾巴。

**沉浸模式 / 操作方式**：底栏（目录 / 书签 / 设置）是浮层，收起时不改变正文区高度，
所以不会触发重新分页、文字不会跳。**顶栏常驻**，它占的空间由它自己填满，正文按
`--chrome-h` 预留，因此顶部不会留出空白。

**宽屏阅读模式（默认开）**：顶栏隐去书名 / 章节 / 返回 / 快速书签，底部状态行也收起，
只在右上角留一个悬浮按钮；点开是一个下拉菜单（进度条 + 目录 / 书签 / 阅读设置 /
返回书架），操作都在里面完成。想换回完整顶栏 + 底栏，在阅读设置里关掉「阅读模式」即可。

**翻页**：点页面左右两侧上一页 / 下一页（中间留空，避免误触）；宽屏右键点正文直接翻到
下一页（选中了文字时让位给浏览器自带的菜单）。手机左右滑动即翻页 —— 横向滑动超过
页宽 12%（或甩得够快）就直接翻过去，不需要滑过半屏。

**位置记忆**：翻页模式记「页 / 总页数」，滚动模式记「scrollTop / 可滚动高度」，
统一成 0–1 的比例存库，因此两种模式、任何字号之间都能互相还原。

**章节识别**：先按行长快速排除（正文段落通常很长），再用句读排除
（标题里不会出现句号），最后匹配这些形态：
`第一章`、`第1章超强作弊高手`、`第十二回`、`卷三 少年时`、`楔子那一场风花雪月`、
`Chapter 12`、以及带分卷前缀的 `洪武大帝 第一章 童年`。
`回`/`部`/`集` 带负向先行，避免把「第一回合…」当成章节。

## 浏览器要求

Chrome / Edge 80+、Safari 16.4+、Firefox 113+
（需要 `DecompressionStream`、IndexedDB、ES modules、`aspect-ratio`、`dvh`、
`backdrop-filter`）。
