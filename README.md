# 墨读 · InkRead

一个**把小说存在浏览器里**的移动端网页阅读器。纯静态、零依赖、无后端：
书籍清单来自一个 JSON 文件，点一下就把小说下载进浏览器的 IndexedDB，
之后离线也能读，并且永远记得你上次读到哪一页。

界面取向是「纸与墨」：暖白纸底、墨色正文、朱砂印章式的点缀，
四个配色主题（纸 / 护眼 / 夜 / 纯黑），为手机竖屏做了专门优化。

## 快速开始

必须通过 HTTP 打开（浏览器不允许 `file://` 页面 fetch 本地 JSON）。

```bash
npm start          # 等价于 node tools/serve.mjs
# 打开 http://localhost:5173/
```

或者用任意静态服务器，例如 `python -m http.server 5173`。

### 在手机上调试

1. 让手机和电脑连同一个 Wi-Fi。
2. 查电脑内网 IP：Windows `ipconfig`，macOS/Linux `ifconfig | grep inet`。
3. 手机浏览器访问 `http://<内网IP>:5173/`。
4. 用「添加到主屏幕」安装，就有一个独立的阅读 App（全屏、无地址栏）。

## 功能

| 功能 | 说明 |
| --- | --- |
| 书库清单 | 从 `data/books.json` 列出所有书，显示书名、作者、标签、篇幅 |
| 下载到本地 | 下载时实时显示百分比，正文写进 IndexedDB，之后**离线可读** |
| 进度记忆 | 自动记录「第几章 + 章内位置」，下次打开精确回到原处（滚动/翻页都支持） |
| 目录 | 底部抽屉列出全部章节，支持搜索，当前章高亮并自动滚到可视区 |
| 书签 | 一键在当前位置加书签，自动摘录一句原文，可跳回、可删除 |
| 继续阅读 | 书架顶部的大卡片，一眼看到在读的书和进度 |
| 两种翻页 | **左右翻页**（横滑/点两侧/键盘）与 **上下滚动**，随时切换 |
| 排版调节 | 字号 14–28px、行距三档、宋/黑/楷三种字体、段首缩进、两端对齐 |
| 四种主题 | 纸、护眼绿、夜、纯黑（OLED），跟随设置全局生效 |
| 离线清单 | 书库清单会缓存在本地，断网也能看到书单 |
| 存储管理 | 查看占用与配额、申请持久化存储、单本删除 / 一键清空 |

**键盘（桌面端）**：`←` `→` 翻页，`↑` `↓` 滚动，`B` 加书签，`Esc` 关闭面板。

## 把自己的书放进来

### 1. 编辑书库清单 `data/books.json`

```json
{
  "name": "我的书库",
  "updatedAt": "2026-09-29",
  "books": [
    {
      "id": "unique-id",
      "title": "书名",
      "author": "作者",
      "intro": "简介，显示在详情页",
      "tags": ["标签", "可多个"],
      "format": "json",
      "url": "data/books/mybook.json",
      "words": 120000
    }
  ]
}
```

`url` 相对清单文件解析，可以指向任何同源地址。

### 2. 准备正文文件

**JSON 格式**（`format: "json"`）

```json
{
  "title": "书名",
  "author": "作者",
  "chapters": [
    { "title": "第一章 起风", "content": "第一段……\n\n第二段……" }
  ]
}
```

`content` 也可以用段落数组：`["第一段", "第二段"]`。

**TXT 格式**（`format: "txt"`）：自动识别章节标题，规则是

- `第X章 / 第一节 / 卷三 / 第十二回` 等（支持中文数字，标题后可跟空格或 `：·-`）
- `序章 / 楔子 / 前言 / 尾声 / 番外 / 后记` 等
- `Chapter 12` / `Part 3`
- 标题行必须独占一行、不超过 34 个字符、不以句号结尾

识别不出标题时会按约 2400 字自动切分，超长段落会按句子边界切开。

```bash
npm test           # 校验清单 + 所有正文文件的解析结果
npm run samples    # 重新生成压测用的 60 章示例（data/books/xinghai.txt）
```

## 数据存在哪

- **正文 / 阅读进度 / 书签** → IndexedDB（库名 `inkread`），不会上传到任何服务器。
- **阅读设置** → localStorage，页面一加载就生效，避免主题闪烁。
- 每条书签记的是「章节序号 + 章内比例」，所以换字号、换字体、横竖屏旋转之后位置依然准确。
- 浏览器在磁盘紧张时可能清理站点数据，代码会在下载后请求 `navigator.storage.persist()`
  申请持久化；书架底部会显示当前是否已持久化。

> 注意：数据属于「这个浏览器 + 这个域名」。换浏览器、换域名、清空站点数据都会丢。

## 目录结构

站点直接放在仓库根目录。Windows 上双击根目录的 `start.bat` 就能起服务，
脚本优先用 Node（`tools/serve.mjs`，带正确的 UTF-8 charset），没装 Node 再退回 Python：

```bat
start.bat              :: 自动挑端口（从 5173 起，被占用就 +1）+ 打开浏览器
start.bat 8080         :: 指定端口
start.bat 8080 -n      :: 指定端口，且不自动打开浏览器
start.bat -h           :: 查看帮助
```

启动后会同时打印「本机地址」和「同一 Wi-Fi 下手机可用的地址」，手机浏览器直接打开即可。
正文放在 `data/books/`、清单写在 `data/books.json`，改完刷新页面就生效，不用重启服务。

> `start.bat` 是**纯 ASCII**（提示语用英文）的，这是刻意的：cmd.exe 解析含多字节字符的
> UTF-8 批处理文件时会错行执行（把半行当成命令），而 GBK/ANSI 版本一旦被编辑器存回
> UTF-8 就会崩。所以脚本里只放启动逻辑，所有中文都在网页和这份文档里。

## 实现要点

**分页**用的是 CSS 多栏 + 原生横向滚动容器：正文元素被固定为一个「一页宽、一页高」
的多栏盒子，内容向左溢出成更多栏，父容器横向滚动并提供原生惯性，松手后吸附到整页。
这样既能用浏览器原生的滚动性能，又能保证「一页就是一页」。
列的间距（44px）特意大于容器左右内边距（21px），否则换页时会在留白里露出上一页的尾巴。

**沉浸模式**：顶部/底部工具栏是浮层，切换时不改变正文区高度，所以不会触发重新分页、
文字不会跳。工具栏无操作 3.6 秒后自动收起，轻触屏幕中部可再次唤出。

**位置记忆**：翻页模式记「页 / 总页数」，滚动模式记「scrollTop / 可滚动高度」，
统一成 0–1 的比例存进 IndexedDB，因此无论哪种模式、什么字号都能还原。

## 浏览器要求

Chrome / Edge 108+、Safari 16.2+、Firefox 113+
（需要 ES modules、IndexedDB、`aspect-ratio`、`dvh`、`overscroll-behavior`、
`backdrop-filter`；页面在更老的浏览器上也能降级显示，但分页与抽屉动效可能不完整）。
